# Open Graph images

Social sharing previews (target **1200×630**). Wired in `lib/site-metadata.ts`.

| File | Used for |
|------|----------|
| `default.png` | Site-wide Open Graph / Twitter card fallback |
| `home.png` | Homepage (`app/page.tsx`) — listed first in metadata |

Replace these PNGs anytime; keep the same filenames or update `ogImagePaths` in `lib/site-metadata.ts`.
